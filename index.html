常见问题

+

什么是生物学年龄（Biological Age）？

生物学年龄（Biological Age，也称生理年龄）是指从生物学角度（包括分子，细胞和组织器官层面）量化的机体真实衰老程度。它不同于您的日历年龄（Chronological Age）——从出生到当前时刻的时间长度。

日历年龄每个人都以每年1岁的速度同等增长，而生物学年龄的增长速度则因人而异。它综合反映了遗传背景、生活方式（饮食、睡眠、运动）、情绪管理、心理压力，以及自然和社会环境对身体造成的真实“磨损”。相比于日历年龄，生物学年龄可以更准确地评估一个人的健康状况和衰老程度。

+

什么是 DNA 甲基化？

DNA（脱氧核糖核酸）是生命遗传信息的载体。它是线性生物大分子，由四种化学碱基——A（腺嘌呤）、C（胞嘧啶）、G（鸟嘌呤）、T（胸腺嘧啶）作为基本单位串联而成。人类的每个细胞核里的DNA约含有30 亿个这样的碱基。在个体的一生中，DNA序列是基本不变的。自发或诱发改变（例如某个位点由 C 转变为 T）的过程被称为突变（Mutation），突变通常是不可逆的。

与突变不同，DNA甲基化（DNA Methylation）是对DNA序列的修饰（modification）。它是在不改变DNA序列的前提下，将一个化学基团甲基（-CH₃），结合到碱基C上。这个过程就像在某个DNA片段上安装了“开关”。与突变不同，甲基化是可逆的（即可以通过去甲基化恢复）。人类DNA中所有C的甲基化状态称为DNA甲基化图谱。

DNA甲基化承载着关键的生物学控制功能。如果一个基因的调控区内的C被大量甲基化修饰，该基因就像被按下了关闭键，进入“沉默”状态。虽然DNA序列一辈子几乎一成不变，但DNA甲基化的状态却是一个动态的过程，受多种内外因素调节。比如：

• 生活方式与环境：个体的饮食习惯、运动频率、心理压力、睡眠质量，生活习惯（吸烟、饮酒）及环境污染等外界刺激，都会实时影响和调整体内 DNA 甲基化状态。
• 体重：体重的变化比如肥胖，会影响和调整体内 DNA 甲基化状态。
• 病毒感染：病毒感染会通过干扰人体细胞的甲基转移酶，诱导特定基因表达，从而改变DNA甲基化水平以逃避人体的免疫清除。
• 疾病早期：比如，在癌症和阿尔茨海默病等疾病的临床前期，细胞异常代谢与慢性炎症会提早触发表观遗传酶类的紊乱，导致抑癌基因或神经保护基因的DNA发生异常甲基化。
• 年龄：随着年龄的增长，人体内特定 DNA 片段的甲基化水平会呈现出规律性的演变，某些区域的甲基化程度会越来越高，而另一些区域则会越来越低。

前沿科学家们正是利用了甲基化随时间演变的特性，通过解析血液或组织中的 DNA甲基化图谱（构建表观遗传钟），来精准量化计算个体的“生物学年龄”（Biological Age），并评估未来的慢性疾病演化风险。

+

为什么 MetaAge 模型比其他的甲基化时钟（DNAm clock）更准确？

单一的甲基化时钟（又称表观遗传时钟，Epigenetic clock）在预测日历年龄的准确性和评估疾病风险的表现上往往欠佳，主要由于以下几种局限性：

  • 位点覆盖有限：只聚焦于特定的甲基化位点（CpG 位点），通常仅涵盖几百个 CpG。
  • 样本规模较小：训练集所依托的样本量较少，统计效能不足。
  • 年龄分布不均一：训练集样本的年龄分布严重失衡（例如绝大部分样品均来自成年人，缺乏儿童与青少年来源的对照基准）。
  • 芯片平台过时：底层训练数据依赖于陈旧的技术平台（如早期的 Illumina 450K 芯片）。

相比之下，MetaAge 是一款前沿的集成机器学习模型（Ensemble Machine-Learning Model）与具备持续自我纠错能力的智能预测系统。它有机整合了包括 Horvath, Hannum, GrimAge V1/V2, PhenoAge, Zhang 以及专门用于捕捉随机衰老变化的 StocP, StocZ, StocH 等近 20 个国际权威时钟所涵盖的核心甲基化位点。通过运用超过 15,000 个跨越全年龄段（0–100岁）的健康人群庞大表观组学数据集作为训练集进行反复交叉验证与算法迭代，MetaAge 能够全面剔除单一时钟的系统性偏差，在提供稳健日历年龄估算的同时，大幅提升了对心血管、退行性疾病风险及全因死亡率的精准预测维度。

+

什么是“年龄加速（Age Acceleration）”？

年龄加速（Age Acceleration, AA）是指基于可量化的生物标志物，判断出一个人的生物学年龄（如 MetaAge 根据血液甲基化图谱测算出来的数值）大于（或小于）其日历年龄的现象。该术语被广泛应用于表观遗传学与现代长寿医学研究。

  • 日历年龄（时序年龄）：您自出生以来的实际时间长度。
  • 生物学年龄（生理年龄）：基于分子，细胞和器官层面计算出来的年龄，反映机体真实的磨损与衰老程度。

如果您的生物学年龄高于实际日历年龄，两者的代数差就被称为正向年龄加速（+AA），代表机体处于加速衰老状态；反之，若低于实际年龄，则称为延缓衰老（-AA）。

从“差值法”到“残差法”的算法演进：
上述简单的两数相减法在统计学上被称为差值法（The Difference Method）。这种方法计算出来的“年龄加速”往往带有系统性偏差（易受受试者自身实际年龄大小的非线性干扰）。 为了彻底消除此类统计学偏倚，Deep-Omics 核心平台 在学术研究与临床交付中，普遍采用更严谨的线性回归残差法（The Residual Method）。 如上图所示，残差法将年龄加速度定义为真实个体偏离群体平均值（回归线 y=x）的**残差距离**（+m 或 -n），从而确保评估结果都具备最高水准的客观性与跨年龄段可比性。

+

如果我的测评结果显示“正向年龄加速”，是否意味着我已经处于病理状态？

请不必恐慌。正向年龄加速（+AA）代表您的机体生理衰老速率快于时序年龄，是身体处于“亚健康磨损”或存在潜在慢性风险的早期信号。与不可逆的基因突变不同，DNA 甲基化修饰状态是动态的，因此具有高度的可逆性。这一结果恰恰为您提供了干预的黄金窗口期。我们的专家团队会结合您的多组学量化结果，为您量身定制涵盖细胞级内源性抗衰、精准代谢调控及暴露组学干预（如作息、压力管理）的个性化方案，帮助您逆转表观遗传年龄，让身体重回健康与年轻状态。

+

我应该多长时间进行一次表观遗传时钟复测？

DNA 甲基化虽然是动态的，但其反映的是细胞和器官层面的深层分子印记，短期的日常波动（如某一天的熬夜）不会使其发生剧烈重构。因此，为了数字化、定量化地监测生活方式调整、精准营养干预或抗衰疗法的真实效果，我们建议每 6 至 12 个月进行一次 Hema-X 或 MetaAge 平台的深度复测。通过多时间点的纵向数据比对，您可以清晰地看到自身衰老速率曲线的放缓或逆转趋势。

+

生活方式的改变真的能延缓或“逆转”我的生物学年龄吗？

是的，科学研究已明确证实了这一点。与一成不变的先天遗传密码（DNA 序列）不同，DNA 甲基化修饰具有高度的动态性与可逆性。这意味着您的行为、环境和生活方式并不会改变您的基因序列，但却能直接决定这些基因的‘开启’或‘关闭’状态。

多项国际前沿的长寿医学临床干预试验表明，通过精准营养干预（如富含特定甲基供体的膳食调控）、科学的规律运动、深度睡眠结构优化、主动式心理压力管理以及消除不良暴露（如戒烟限酒），能够有效靶向调控特定基因调控区上的甲基化修饰状态。这种细胞与组织器官深层生理印记的系统性重构，在临床多组学层面上便表现为生物学年龄的显著减小，即实现了分子层面的‘表观遗传学逆转’。

+

进行这些检测需要提供什么样本？

我们的大部分检测项目（如基于 Hema-X 平台的深度推演、免疫效能与外周应激激素评估等）仅需要微量的外周血全血样本，采样过程高效且无创。

+

表观遗传钟能够精准预测我的寿命或疾病发生时间吗？

表观遗传钟并不是一个决定性的“生命倒计时器”，它无法预测突发事件或完全不可控的环境因素。它的核心价值在于基于大规模人群数据的统计学风险评估。高级模型（如集成算法 MetaAge）通过测量您当前的系统性生理衰老速率，可用于评估未来发生心血管疾病、II 型糖尿病、神经退行性疾病（如阿尔茨海默病）以及全因死亡风险的相对风险水平。它更像是长寿医学中的“早期预警雷达”，帮助您在临床症状出现前的 5–10 年发现潜在分子风险，从而尽早采取生活方式优化与精准干预，而非对未来作出宿命式预测。

什么是“分子画像服务”？它在司法鉴定或筛查中如何发挥作用？

分子画像（Molecular Phenotyping）是一项基于分子（或基因型）数据的表型反向推演技术。当传统司法 DNA STR 数据库比对未命中时，Deep-Omics 利用检材中独特的 DNA 甲基化图谱，深度重构涉案人员或未知个体的核心表型特征。我们能够高精度反向推演其真实的生物学年龄（误差通常在 ±2 岁以内）、解密生理性别、评估体型特征（BMI），甚至能够精确破译其长期的暴露组学史（如是否有重度吸烟史、药物滥用、特定环境毒素暴露历史或 HIV 感染状态），为复杂案件的排查、失踪人口追踪及特定合规审查提供底层、不可伪造的科学画像支撑。

Deep-Omics 如何保障我的个人基因与多组学数据隐私安全？

我们深知，多组学数据承载着个人最核心、最敏感的生物隐私信息。Deep-Omics 严格遵循国际最高标准的数据安全与隐私保护规范，建立了符合 HIPAA/GDPR 等国际合规要求的数据治理与安全体系，全面保障您的数据安全与个人隐私。

  • 样本去隐私化：所有进入实验室的样本均通过随机生成的唯一条形码（Barcode）进行标识，实验流程中不包含任何可直接识别个人身份的临床信息，确保实验人员无法获知您的身份信息。
  • 加密存储与计算：Deep-Omics 多组学分析管线基于 Google Cloud Platform（GCP）企业级安全架构开展分布式计算。所有原始测序数据（如 FASTQ、CRAM 文件）及甲基化矩阵数据，均采用高强度加密机制进行传输与云端存储，确保数据全生命周期安全。
  • 严格权限控制：最终分析报告通过加密安全通道进行交付。未经您本人明确授权或法律法规要求，任何第三方（包括科研合作机构）均无权访问或查阅您的原始多组学数据及相关个人信息。
